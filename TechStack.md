# Tech Stack

## Python Desktop Translator

- Python 3.8+
- CustomTkinter 5.2.2
- Pillow 11.0.0
- chardet 5.2.0
- requests 2.32.3 or newer
- python-dotenv 1.0.1 or newer
- DeepL REST API

## Rust Archive Module

- Rust 2021 edition
- Cargo package: `archive_module` 0.1.0
- Standard library only in the current MVP

## Future Archive Dependencies

- Oodle bindings for Kraken/Mermaid decompression after licensing and distribution rules are confirmed.
- Zstandard support for archives that use `.zstd` compression.
- LZ4 support if required by target Unreal builds.
